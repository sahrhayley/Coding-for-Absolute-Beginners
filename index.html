Coding for Absolute Beginners

A no-fluff guide to what code is, what it does, and how to make your first tiny website.

What the fuck is coding?

It's just writing instructions for a computer. Seriously.

The basic idea

Code tells computers what to do.

Websites, apps, and games all follow instructions written in code. Different languages handle different jobs.

Your first goal

Make one tiny webpage.

Start with words and a button. Then change its colors. Then make the button do something.

You do not have to memorize code. Look things up, try stuff, break things, and fix them. That's normal.

Your path

  1. 1
    HTML — put things on a page.
  2. 2
    CSS — make them look how you want.
  3. 3
    JavaScript — make them respond to clicks.

What does each language do?

Start with the first three. The others can wait.

Learn first

🏗️ HTML

Structure. Adds headings, paragraphs, pictures, links, and buttons.

Learn second

🎨 CSS

Appearance. Changes colors, fonts, sizes, spacing, and layouts.

Learn third

⚡ JavaScript

Interaction. Makes things react to clicks, change, and keep score.

Remember: HTML creates a button. CSS makes it pink. JavaScript makes it work.

🐍 Python — later

Used for general programming, calculations, automations, and tools.

🗄️ SQL — later

Used to retrieve and manage information in databases, such as appointments or inventory.

Code explained, minus the headache

Here's what you're looking at in the example.

HTML

Tags tell the browser what something is.

<h1>My First Website</h1>
<p>Hello!</p>
<button>Click Me!</button>

What each part means

<h1>
Creates a large heading.
</h1>
A closing tag. It tells the browser where the heading ends.
<p>
Creates a paragraph of text.
<button>
Creates a clickable button.
CSS

Rules tell the browser what to style.

h1 {
  color: purple;
}

What each part means

h1
Selects the heading you want to style.
{ }
Holds the styling instructions together.
color
The property that changes text color.
:
Separates a property from its value.
purple
The color chosen for this example.
;
Ends that styling instruction.
Important: This changes the heading's color, not the button's. To style a button, use button { ... }.
JavaScript

A function is a named set of instructions.

function changeText() {
  document.getElementById("message").innerText =
    "You clicked the button!";
}

What each part means

function
Starts a reusable set of instructions.
changeText
The name we gave this function.
()
Holds inputs to the function. Empty in this example.
{ }
Holds the instructions the function runs.
document
Refers to the webpage.
getElementById("message")
Finds the HTML element with id="message".
.innerText
Refers to the text inside that element.
=
Sets a new value, replacing the old text.
"You clicked the button!"
The new words to display.
onclick="changeText()"
Tells the HTML button to run this function when clicked.
Formatting

Why does code look “pretty”?

These two CSS examples work the same way:

h1 { color: purple; font-size: 30px; }
h1 {
  color: purple;
  font-size: 30px;
}

What each part means

Line breaks
Separate instructions so they're easier to read for humans.
Indentation
Shows which pieces of code belong together.
Punctuation
Braces, quotes, and other symbols often matter even when spaces don't.
Same result, easier to read. Most CSS spacing can change without affecting the result. Some JavaScript line breaks do matter.
